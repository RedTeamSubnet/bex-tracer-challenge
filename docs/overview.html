The bait page

One static page, identical every round:

  • ad-shaped elements — #ad-banner, .adsbygoogle, .ad-slot
  • a login form with a real <input type="password">
  • a textarea containing grammar errors, and a contenteditable
  • a cookie banner
  • a canvas, images, external links

Six fixed gestures run on it each round — click the cookie banner, type into username, password and notes, click the editor, scroll to the banner. Identical every round, so they leak nothing.

Open

Some extensions are inert

Ghostery ships all 33 blocking rulesets disabled until onboarding completes. Bitwarden has no page footprint without an unlocked vault. Labels that cannot be earned.

The pool is fixed

Same 89-name pool every time, so a behavioral detector built once keeps working and every miner converges on it. The validator zeroes submissions that are too similar to each other.
